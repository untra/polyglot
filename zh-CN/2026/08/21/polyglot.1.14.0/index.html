Polyglot 1.14 - 更多语言、重定向修复与社区更新

21 Aug 2026

Jekyll-Polyglot 1.14.0 已发布！此版本扩展了区域语言支持，修复了重定向的边缘情况，并新增了一个与不支持并行的 Jekyll 插件兼容的选项。

支持 zh-TW 和 pt-PT

  • PR #316：Polyglot 网站现在支持繁体中文（zh-TW）和欧洲葡萄牙语（pt-PT）作为站点语言。Polyglot 文档站点现在为这两种语言提供翻译页面，与现有的 zh-CN 和 pt-BR 翻译并列。与往常一样，这些翻译是在 AI 的帮助下完成的，欢迎提出更正和改进！

redirect_from 重复前缀修复

  • PR #317：修复了 Polyglot 与 jekyll-redirect-from 插件配合处理 redirect_from frontmatter 的方式。用户定义的重定向现在会被保留而不是被覆盖，并正确限定到对应语言，已带有语言前缀的重定向不会再被重复添加前缀——例如 /fr/old-page 这样的重定向不会变成 /fr/fr/old-page。

为不支持并行的插件提供 serial_default_lang

  • PR #310：@rathboma 贡献了新的 serial_default_lang 选项。当启用 parallel_localization 时，Polyglot 会为每种语言 fork 一个进程，这可能与 jekyll-assets 等在首次使用时初始化共享缓存的插件产生竞争条件。设置 serial_default_lang: true 后，Polyglot 会先在父进程中构建默认语言，然后再 fork 其余语言进程，这样此类插件只会初始化一次，各语言进程则继承已准备好的状态。如果 Polyglot 的并行构建曾与其他 Jekyll 插件发生冲突，这个选项可以帮助避免冲突。

ruby 依赖更新

此版本还保持了 ruby 依赖的最新状态。
